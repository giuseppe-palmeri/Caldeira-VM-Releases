A lightweight, deterministic virtual machine for microcontrollers.

Caldeira VM provides a stable execution environment for embedded applications: deterministic execution, hardware portability, and predictable behavior — built for long-lived embedded software, maintainable firmware, and an open developer ecosystem.

Install Caldeira VM

Install the latest public bootstrap environment with one command.

Terminal
$ curl -fsSL https://raw.githubusercontent.com/giuseppe-palmeri/Caldeira-VM-Releases/main/caldeira-bootstrap.sh | bash

The bootstrap script downloads and manages Caldeira VM SDK versions. It requires curl, python3 and unzip.

Develop in VS Code

A full-featured extension brings Caldeira VM development into Visual Studio Code: language support, debugging, and project commands.

Language support

Syntax highlighting for the Clasto assembly language, plus an LSP server providing real-time diagnostics, completions, hover documentation, go-to-definition, rename, and formatting.

Integrated debugging

A built-in debug adapter debugs your program with breakpoints (including conditional and hit-count), VM registers and local variables, fault and panic detection, and a bytecode disassembly view.

Project commands

Build, run, debug, scaffold new projects, install the VM, flash, and diagnose faults — all from the command palette or the editor context menu.

Why Caldeira VM

Modern embedded systems often require long product lifetimes, maintainable firmware, and predictable behavior. Caldeira VM is designed around these constraints.

Architecture

Caldeira VM is composed of two layers: a public open ecosystem and a proprietary core.

Open ecosystem
  • Bytecode specification
  • Assembler
  • SDK
  • Documentation
  • Examples
↓
Proprietary core
  • Target-specific runtime
  • Optimized execution engine
  • Commercial deployment component

The proprietary core is owned by Sky Home Srl. Commercial products integrating it require a separate commercial license. It is not open source and is not publicly downloadable.

Open ecosystem

Public components are provided to encourage experimentation, learning, development, and ecosystem growth.
