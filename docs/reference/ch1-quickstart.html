rocket_launch 1. Primo programma

Caldeira VM e' una macchina virtuale deterministica per sistemi embedded. Scrivi il tuo programma in un file .clasto, lo compili con clasto in bytecode .lava, e lo esegui con lava.

1.1 Il tuo primo programma

Crea un file primo.clasto:

.VECTOR EVT_RESET(flags:FLG), main
main:
    MOV.S R1, 42
    HALT

Salva, compila ed esegui:

clasto primo.clasto primo.lava
lava primo.lava

La VM parte, carica R1=42, poi si ferma (HALT) e torna in stato IDLE. Questo e' un programma Caldeira funzionante.

1.2 Aggiungere dati: .CONST e .STATIC

Le costanti si definiscono a compile-time con .CONST. I dati inizializzati vanno in .STATIC ... .END_STATIC:

.CONST BUF_SIZE 64

.STATIC
msg:
    .TEXT "Ciao Mondo!"
.END_STATIC

.VECTOR EVT_RESET(flags:FLG), main
main:
    LDA R1, msg        ; R1 = indirizzo RAM di msg (scrivibile)
    HALT

.STATIC copia i dati dalla flash alla RAM all'avvio. LDA carica l'indirizzo in RAM (leggibile e scrivibile).

1.3 Ciclo di sviluppo

ComandoCosa fa
clasto sorgente.clasto output.lavaCompila in bytecode
lava output.lavaEsegue il bytecode
lava -v1 output.lavaEsegue con output verboso (stato finale)
clasto -l sorgente.clastoElenca le VM in un sorgente multi-VM

1.4 Esempio completo: Contatore con classe

Questo esempio dimostra classi, metodi, fault handling e stack. Copia in demo.clasto, compila ed esegui.

Esempio: templates/examples/DEMO.clasto 
; Comprehensive demo program
; Demonstrates classes, methods, stack usage, fault handling and the special
; registers R13 (this), R14 (fault code) and R15 (stack pointer).
.FILE "demo.clasto"

.VECTOR EVT_RESET(flags:FLG), main

.CLASS Counter
    .FIELD value:U16           ; offset 4 (after the 4-byte object header)
    .FIELD limit:U16           ; offset 6

    .METHOD Init               ; limit argument passed in R2 (no ABI declared)
        MOV.S R1, 0
        ST16 R1, 4(R13)        ; value = 0
        ST16 R2, 6(R13)        ; limit = R2
        RET

    .METHOD Increment
        LD16 R1, 4(R13)        ; load value
        LD16 R2, 6(R13)        ; load limit
        ADD.S R1, R1, 1
        CMP R1, R2
        BLT no_overflow
        MOV.S R1, 0            ; limit reached: wrap around to zero
no_overflow:
        ST16 R1, 4(R13)
        RET

    .METHOD GetValue
        LD16 R1, 4(R13)        ; R1 = return value
        RET
.END_CLASS

main:
    ; Save the registers we keep across the whole program
    PUSH R8
    PUSH R9

    ; Create a Counter object in the scratch arena
    MARK                     ; save scratch position
    NEW R8, %Counter         ; R8 = new Counter instance
    MOV.S R2, 10             ; limit = 10
    CALLM R8, %Counter.Init

    ; Loop: increment the counter and read it back
    MOV.S R9, 0
loop:
    CALLM R8, %Counter.Increment
    CALLM R8, %Counter.GetValue
    ADD.S R9, R9, 1
    CMP.S R9, 15
    BLT loop

    ; Protect a division against faults
    GUARD fault_handler
    MOV.S R1, 42
    MOV.S R2, 0
    DIV R3, R1, R2            ; division by zero -> fault
    UNGUARD
    JMP done

fault_handler:
    ; R14 holds the fault code (FAULT_DIV_ZERO); R15 restored to checkpoint
    ADD R10, R14, R0          ; R10 = fault code
    UNGUARD

done:
    FREE                     ; scratch arena back to MARK
    POP R9
    POP R8
    EXIT 0
