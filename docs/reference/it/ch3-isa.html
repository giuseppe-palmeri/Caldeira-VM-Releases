code 3. Set di istruzioni (ISA)

Reference completo delle istruzioni Caldeira VM, organizzate per categoria.

Aritmetica e logica

Operazioni aritmetiche e logiche su registri a 32 bit.

1 / 12
ADD ADD Rd, Rs1, Rs2
Descrizione
Somma Rs1 e Rs2 (Rd = Rs1 + Rs2).
Il risultato è troncato a 32 bit (modulo 2^32).
Non modifica i flag PSR: per confronti usare CMP prima di un branch.
Flags PSR
none
Fault
none
Esempio: templates/examples/ADD.clasto 
; Arithmetic examples
; Demonstrates ADD, SUB, MUL, DIV, MOD (register operands)
.FILE "add.clasto"
.CONST A 20
.CONST B 6

main:
    MOV.S R1, A
    MOV.S R2, B

    ; ADD: sum of two registers
    ADD R3, R1, R2            ; R3 = 20 + 6 = 26

    ; SUB: difference
    SUB R4, R1, R2            ; R4 = 20 - 6 = 14

    ; MUL: 32-bit product (truncated)
    MUL R5, R1, R2            ; R5 = 20 * 6 = 120

    ; DIV: integer division, truncated toward zero
    DIV R6, R1, R2            ; R6 = 20 / 6 = 3

    ; MOD: remainder of the division (sign of dividend)
    MOD R7, R1, R2            ; R7 = 20 % 6 = 2

    ; None of these instructions touch the PSR flags:
    ; use CMP before a branch to compare values.
    EXIT 0

AND AND Rd, Rs1, Rs2
Descrizione
AND bit-a-bit tra Rs1 e Rs2 (Rd = Rs1 & Rs2).
Utile per mascherare bit specifici: i bit con 1 in Rs2 vengono preservati, quelli con 0 vengono azzerati.
Flags PSR
none
Fault
none
Esempio: templates/examples/BITWISE.clasto 
; Bitwise operation examples
; Demonstrates AND, OR, XOR, SHL, SHR, ASR, NOT
.FILE "bitwise.clasto"

main:
    ; --- AND: mask specific bits ---
    MOV.S R1, 0xFF
    MOV.S R2, 0x0F
    AND R3, R1, R2            ; R3 = 0xFF & 0x0F = 0x0F

    ; --- OR: set specific bits ---
    MOV.S R1, 0xF0
    MOV.S R2, 0x0F
    OR R4, R1, R2             ; R4 = 0xF0 | 0x0F = 0xFF

    ; --- XOR: toggle specific bits ---
    MOV.S R1, 0xFF
    MOV.S R2, 0x0F
    XOR R5, R1, R2            ; R5 = 0xFF ^ 0x0F = 0xF0

    ; --- SHL: logical shift left (zeros enter from the right) ---
    MOV.S R1, 1
    MOV.S R2, 4
    SHL R6, R1, R2            ; R6 = 1 << 4 = 16

    ; --- SHR: logical shift right (zeros enter from the left) ---
    MOV.S R1, -32768
    MOV.S R2, 4
    SHR R7, R1, R2            ; R7 = 0x0800

    ; --- ASR: arithmetic shift right (sign bit is replicated) ---
    MOV.S R1, -8
    MOV.S R2, 1
    ASR R8, R1, R2            ; R8 = -4

    ; --- NOT: bitwise complement ---
    MOV.S R1, 0x0F
    NOT R9, R1                ; R9 = ~0x0F = 0xFFFFFFF0

    EXIT 0

ASR ASR Rd, Rs1, Rs2
Descrizione
Shift aritmetico a destra di Rs1: Rd = Rs1 >> Rs2 (con estensione del segno).
A differenza dello shift logico, il bit di segno (MSB) viene replicato a sinistra, preservando il segno del numero.
Solo i 5 bit meno significativi di Rs2 determinano lo spostamento (0-31 posizioni).
Utile per divisioni per potenze di 2 con numeri con segno.
Non modifica i flag PSR.
Flags PSR
none
Fault
none

Confronto e salti condizionali

Confronto e branch basati su flag PSR.

1 / 7

Descrizione
Confronta Rs1 con Rs2 calcolando Rs1 - Rs2 senza memorizzare il risultato.
Aggiorna i flag PSR per i successivi branch condizionali:

- Z (Zero): 1 se Rs1 == Rs2
- N (Negative): 1 se il bit 31 del risultato è 1
- C (Carry): 1 se Rs1 < Rs2 (unsigned, prestito)
- V (oVerflow): 1 se c'è overflow signed nella sottrazione

Per i branch signed si usano N e V insieme: BLT=BGE verificano N!=V / N==V.
I registri non vengono modificati.
Flags PSR
Z, N, C, V
Fault
none

    MOV.S R1, 64            ; 64 bytes

Protezione (fault handling)

Checkpoint GUARD/UNGUARD e fault espliciti.

1 / 3
GUARD GUARD Label
Descrizione
Crea un checkpoint per la gestione delle eccezioni (simile a setjmp).
Salva lo stato della VM (registri, SP) e fa un MARK implicito sullo Scratch Arena.
Se nel codice protetto si verifica una fault, la VM ripristina il checkpoint: registri e scratch tornano allo stato precedente, R14 riceve il codice di fault, e l'esecuzione riprende dall'handler Label.
Un fault nell'handler di un GUARD annidato (prima del suo UNGUARD) PROPAGA al GUARD esterno ancora attivo, con R14 = codice del nuovo fault; se nessun frame è usabile (doppio fault), la VM va in stato FAULT.
RIENTRO (retry): ri-eseguire lo STESSO GUARD (es. l'handler salta alla sua label) dopo un recovery RIARMA il frame invece di pusharne uno nuovo — come ri-eseguire setjmp in C. I retry sono illimitati, lo snapshot viene riscattato al riarmo (un contatore di retry in un registro sopravvive) e il programma deve limitare i retry esplicitamente. Il PANIC resta solo per GUARD distinti annidati senza UNGUARD.
Il blocco va chiuso con UNGUARD, che sul percorso normale libera il MARK (FREE implicito).
La chiusura è anche IMPLICITA: a RET per i GUARD aperti nella routine che
ritorna (niente scope creep nel chiamante), a HALT/EXIT per tutti i GUARD aperti.
Il frame arena NON viene toccato: per rollback del frame, fare MARK.FR esplicito.
Se il numero di checkpoint annidati supera il limite, la VM va in stato PANIC.
Flags PSR
none
Fault
none

    MOV.S R1, -241         ; R1 = 0xFF0F (but sign-extended: 0xFFFFFF0F)

    EXIT 1

    CMP.S R4, 42
    BEQ equal                 ; Z=1 -> taken
    EXIT 1

    CMP.S R4, 43
    BNE not_equal             ; Z=0 -> taken
    EXIT 1
