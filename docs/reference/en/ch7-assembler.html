article 7. Direttive e macro assembler

Questo capitolo descrive tutto ciò che puoi scrivere in un file .clasto oltre alle istruzioni della VM. Le direttive (cominciano con .) controllano l'assemblatore a compile-time: definiscono costanti, includono file, dichiarano classi, configurano la memoria. Le pseudo-istruzioni (cominciano con !) sono scorciatoie per operazioni comuni come caricare un valore a 32-bit. Le macro (.MACRO) ti permettono di creare i tuoi comandi riutilizzabili.

7.1 Direttive

Le direttive controllano l'assemblatore e non generano direttamente codice macchina.

DirettivaSintassiDescrizione
.FILE.FILE "nomefile"Registra il nome del file sorgente corrente per debug (riga/colonna negli errori). Mettilo all'inizio di ogni file incluso per tracciare l'origine degli errori.
.CLASS.CLASS NomeClasseApre un blocco classe. Usa .FIELD per i campi e .METHOD per i metodi. Chiudi con .END_CLASS per generare il Class Descriptor (header + VTable).
.INTERFACE.INTERFACE NomeDichiara un contratto: solo firme metodi (.METHOD), senza codice. Una classe implementa un'interfaccia con .CLASS Nome IMPLEMENTS Interfaccia.
.END_INTERFACE.END_INTERFACEChiude un blocco .INTERFACE. Dopo non puoi piu aggiungere metodi all'interfaccia.
.END_CLASS.END_CLASSChiude .CLASS. L'assembler scrive Class Descriptor (header + VTable) e verifica che ogni metodo termini con RET e che l'interfaccia sia completamente implementata.
.FIELD.FIELD Nome:TipoDichiara un campo nella classe corrente. Tipi: U8, U16, U32, PTR, FLG. I campi vengono riordinati per dimensione e allineati. Il : e' convenzionale (es. .FIELD value:U16).
.METHOD.METHOD Nome(tipo:TIPO, ...)Dichiara un metodo con parametri tipizzati. Es. .METHOD Incrementa(amount:U16). I parametri sono accessibili su R13 con offset (il primo a offset 4).
.VECTOR.VECTOR Evento(ABI), LabelCollega un evento (es. EVT_RESET, EVT_TICK_1MS) a un handler. .VECTOR NomeEvento(param:TIPO), label_handler. L'ABI valida i parametri dell'evento.
.CONST.CONST Nome:ValoreDefinisce una costante numerica risolta a compile-time. Usala in .IF, .CONFIG o come immediato (MOV.S R1, MAX_BUF). Il : e' convenzionale.
.ABI.ABI (nome:TIPO, ...) -> (out:TIPO) / .END_ABIDentro un blocco .ABI ... .END_ABI, i registri R1-R15 vengono rinominati con nomi logici (es. .ABI EVT_TICK_1MS(tick:FLG) ... MOV R8, tick .END_ABI). L'ABI può riferirsi a eventi o syscall per validare i tipi automaticamente.
.INCLUDE.INCLUDE "file"Incorpora il contenuto di un altro file .clasto come se fosse scritto li'. Usalo per condividere costanti e interfacce tra file. Il percorso e' relativo al file corrente o alla directory -I. Inclusioni multiple vengono ignorate.
.DB.DB b1, b2, ... (dentro .STATIC)Emette byte costanti nel bytecode. Dentro .STATIC accumula dati (max 512 byte totali). Metti una label prima per accedere con LDA (RAM) o MOV.S (flash).
.DW.DW w1, w2, ... (dentro .STATIC)Emette halfword (16-bit) costanti. Dentro .STATIC per tabelle di lookup o valori a 2 byte con label prima per LDA.
.DD.DD d1, d2, ... (dentro .STATIC)Emette word (32-bit) costanti in little-endian. Dentro .STATIC per puntatori, flag a 32-bit o tabelle numeriche.
.TEXT.TEXT "testo" (dentro .STATIC)Emette una stringa con null terminator e padding a 4 byte. Supporta escape: \n, \r, \t, \0, \\. Metti una label prima per accedere con LDA.
.IF.IF expr / .ELSE / .END_IFAssemblaggio condizionale: se l'espressione e' vera include il blocco, altrimenti lo salta. Supporta ==, !=, &lt;, &gt;, defined(), !, &&, ||. (<a href="#ch6-if">vedi espressioni</a>)
.VM.VM nome / ... / .END_VMDelimita il codice di una VM in un sorgente multi-VM. Il CLI (clasto) elabora ogni blocco .VM ... .END_VM separatamente e produce un file .magma (container multi-VM). Serve solo per firmware con piu VM isolate.
.PRINT.PRINT "msg"Scrive un messaggio su stderr durante l'assemblaggio. Non blocca la compilazione. Utile per debug di .IF e .MACRO.
.ERROR.ERROR "msg"Scrive un errore su stderr e blocca la generazione del bytecode. Usalo per validazioni personalizzate (.IF ... .ELSE .ERROR "msg" .END_IF).
.LOC.LOC numeroForza il numero di riga interno dell'assemblatore. Utile per file preprocessati con mapping righe diverso.
.ALIAS.ALIAS nome:Tipo, RxRinomina un registro (R0-R15) con un nome simbolico globale; il tipo (U8/U16/U32/S8/S16/S32/PTR/FLG, anche array Tipo[N]...) e' obbligatorio. Es. .ALIAS counter:U32, R8 -> puoi usare counter come registro. Senza tipo -> E1503, tipo invalido -> E1504; accessi indicizzati fuori range -> E3010/E3011/E3012, larghezza LD/ST diversa dall'elemento -> E3013, alias REG nudo come offset -> E3014, alias OFFSET nudo -> E3015.
.MACRO.MACRO nome arg1, ... / .END_MACRODefinisce una macro richiamabile con !nome. I parametri si usano con #nome. Es. .MACRO ADD3 r1,r2,r3 ... ADD #r1, #r2, #r3 ... .END_MACRO.
.SCOPE.SCOPE [nome] / .END_SCOPEBlocco di contesto: dentro .SCOPE le .CONST, gli .ALIAS, le label e i .PROTECT sono locali al blocco (shadowing legale). Il KEEP e' stato RIMOSSO: per la protezione per-call usare .KEEP Rx ... .END_KEEP.
.SLOT.SLOT id ... .END_SLOTBlocco riscrivibile (stile slot template): il file incluso dichiara il default, la glue riapre lo stesso id con il corpo vincente. Semantica "l'ultimo vince" (come .VECTOR): alla prima occorrenza (ancora) viene emesso il contenuto dell'ultima definizione. Senza override il default resta (compatibilita' totale). Espansione testuale dopo le .INCLUDE.
.PROTECT.PROTECT Rx | alias, ...Dichiara un registro "prezioso" che deve sopravvivere a ogni chiamata di routine. L'assembler verifica (post-pass) che nessuna routine chiamata clobberi un registro protetto letto dal chiamante dopo la CALL (E2100). R0 (zero) e R15 (SP) non sono proteggibili (E2102). Pattern riconosciuto: PUSH R13 ... CALL ... POP R13.
.WHILE.WHILE Rd, Rs, COND / .END_WHILECiclo a compile-time: confronta Rd con Rs, se COND (EQ/NE/GT/GE/LT/LE) e' falsa salta a .END_WHILE. Attenzione: se la condizione e' sempre vera, il ciclo si ripete all'infinito e l'assemblatore non termina.
.STATIC.STATIC ... .END_STATICBlocco di dati copiati da flash a RAM all'avvio (leggibili/scrivibili). LDA da' indirizzo RAM; label in MOV.S da' indirizzo flash (sola lettura). Max 512 byte.
.SHARED.SHARED nImposta la memoria condivisa in KB (n >= 8). Se usato piu volte, prevale il valore massimo. Default: 64KB.
.SWITCH.SWITCH expr ... .CASE val / .DEFAULT ... .END_SWITCHSelezione compile-time a N rami: valuta l'espressione costante UNA volta e attiva il ramo .CASE con valore uguale (o il .DEFAULT se nessun caso matcha); i rami non attivi non vengono assemblati. Max 8 livelli di annidamento.
.ENUM.ENUM [Nome] ... .END_ENUMCostanti in serie: ogni voce diventa una .CONST (con prefisso Nome.Voce se l'enum ha un nome), valore ad auto-incremento con override esplicito (= val). Es. .ENUM Color / RED / GREEN / BLUE = 10 / ALPHA / .END_ENUM -> Color.RED=0, Color.GREEN=1, Color.BLUE=10, Color.ALPHA=11.
.FOR.FOR var, start, limit [, step] ... .END_FORLoop compile-time con variabile: replica il corpo per ogni valore di var da start a limit (limite esclusivo, stile C), step opzionale anche negativo; nel corpo la variabile si usa come #var. I bound accettano numeri, .CONST ed espressioni (N+2, CNT*2). .FOR e' annidabile (variabili distinte, anche referenze incrociate #i/#j). Max 10000 iterazioni.
.ALIGN.ALIGN nAllinea l'indirizzo corrente al prossimo multiplo di n (potenza di due, 1-64): nei dati (.STATIC) padding a byte zero, nel codice no-op fino all'allineamento (arrotondato al multiplo di 4).
.ASSERT.ASSERT cond, "msg"Verifica compile-time: se la condizione costante e' falsa l'assemblaggio fallisce con il messaggio (E1438). Es. .ASSERT N < 8, "N fuori range".

6.2 Struttura file e utilità

Un file .clasto contiene una riga per ogni operazione. Ogni riga può avere:
- una istruzione: ADD R1, R2, R3
- una direttiva (comincia con .): .CONST MAX 100
- una pseudo-istruzione (comincia con !): !LI R1, 42
- una etichetta (nome + :): loop:
- un commento (;): tutto dopo ; viene ignorato

Ciclo di sviluppo: clasto input.clasto output.lava poi lava output.lava.

Direttive di utilitá:
.FILE "nome" registra il nome file per il debug.
.LOC n forza il numero di riga.
.PRINT "msg" scrive su stderr.
.ERROR "msg" blocca la compilazione.

6.3 Dati e costanti

.CONST Nome:Valore definisce costanti numeriche risolte a compile-time — usale in .IF, .CONFIG o come immediato nelle istruzioni (es. MOV.S R1, MAX_BUF). Il : e' convenzionale, puoi usare anche .CONST Nome Valore.

Letterali numerici: i numeri si scrivono in decimale (42), esadecimale (0x2A), ottale (0o52) o binario (0b101010). Tutte le basi sono valide ovunque serva un numero (immediati, .CONST, espressioni, .DB/.DW/.DD) e si possono mescolare nelle espressioni. Limite: 32 bit; oltre -> E0006.

.DB (byte), .DW (halfword 16-bit), .DD (word 32-bit) e .TEXT (stringa) emettono dati costanti nel bytecode. Metti una label prima (es. tabella:) per poterli raggiungere.

.STATIC ... .END_STATIC crea una sezione di dati che all'avvio della VM viene copiata dalla flash alla RAM privata, quindi sono leggibili e scrivibili. LDA carica l'indirizzo in RAM (per read/write con ST). Usare la label direttamente in MOV.S da' l'indirizzo flash (sola lettura, piu veloce). Max 512 byte totali.

.DB 0x01, 0x02, 0xFF              ; 3 byte
.DW 0x1234, 0x5678                 ; 2 halfword
.DD 0xDEADBEEF, 0xCAFEBABE        ; 2 word
.TEXT "Hello, World!"              ; stringa + null

6.4 Condizionali e ripetizioni

.IF expr ... .ELSE ... .END_IF valuta un'espressione a compile-time: se il risultato e' diverso da zero, il blocco viene incluso nel bytecode, altrimenti viene saltato. Supporta ==, !=, <, >, <=, >=, defined(), !, &&, || e parentesi.

.FOR var, start, limit [, step] ... .END_FOR replica il corpo per ogni valore di var da start a limit (limite esclusivo, stile C), step anche negativo; nel corpo la variabile si usa come #var. I bound accettano numeri, .CONST ed espressioni (N+2, CNT*2) e i .FOR sono annidabili (variabili distinte, anche referenze incrociate #i/#j).

.SWITCH expr ... .CASE val / .DEFAULT ... .END_SWITCH e' la selezione compile-time a N rami: valuta l'espressione costante UNA volta e attiva il ramo .CASE con valore uguale (o il .DEFAULT se nessun caso matcha); i rami non attivi non vengono assemblati.

.ENUM [Nome] ... .END_ENUM genera costanti in serie (auto-incremento, override con = val; con nome le voci diventano Nome.Voce). .ALIGN n allinea l'indirizzo al prossimo multiplo di n (potenza di due). .ASSERT cond, "msg" fa fallire l'assemblaggio se la condizione costante e' falsa.

SintassiEsempioDescrizione
defined(nome).IF defined(DEBUG)Vero se nome è definito come .CONST
defined nome.IF defined DEBUGStesso significato, senza parentesi
a == b.IF VM_FEATURE_GDB == 1Uguale
a != b.IF VER_MAJ != 2Diverso
a < b.IF COUNT < 10Minore (signed)
a <= b.IF X <= YMinore o uguale
a > b.IF SIZE > 0Maggiore
a >= b.IF N >= 3Maggiore o uguale
! expr.IF !defined(DEBUG)NOT logico
a && b.IF (X > 0) && (X < 10)AND logico
a || b.IF (A == 1) || (B == 2)OR logico
(expr).IF (A > 0) && (B < 5)Raggruppamento parentesi
numero.IF 1Qualsiasi valore diverso da zero è vero
 
.IF defined(MY_FLAG)          ; vero se MY_FLAG è definito
    MOV.S R1, 10
.ELSE
    MOV.S R1, 0
.END_IF

.IF VM_FEATURE_GDB == 1   ; confronto con costante
    MOV.S R1, 100
.END_IF

.IF (X > 0) && (Y < 10)  ; espressione composta
    HALT
.END_IF

6.5 Modularizzazione

.INCLUDE "file" incorpora il contenuto di un altro file .clasto nel punto corrente, come se il testo fosse scritto li'. Usalo per condividere costanti, definizioni di interfacce o macro tra piu file.

Il percorso e' relativo alla directory del file corrente (o alla directory specificata con -I). Se lo stesso file viene incluso piu volte, le successive vengono ignorate automaticamente.

.INCLUDE "vm_consts.inc.clasto"     ; costanti VM
.INCLUDE "platform/io.clasto"       ; driver I/O

6.6 Pseudo-istruzioni e macro

!LI Rd, valore (Load Immediate, signed) carica un valore a 32-bit in un registro. Se il valore sta in 16 bit signed genera una MOV.S (1 word), altrimenti MOV.S + MOV.H (2 word). !LU Rd, valore (Load Unsigned) fa lo stesso ma con MOV.U invece di MOV.S. Entrambe accettano numeri e label.

.MACRO nome arg1, arg2 ... .END_MACRO definisce una macro riutilizzabile. I parametri si riferiscono con #nome nel corpo. La macro si richiama con !nome.

.ALIAS nome:Tipo, Rx associa un nome simbolico a un registro R0-R15 per tutto il file; il tipo (U8/U16/U32/S8/S16/S32/PTR/FLG, anche array) e' obbligatorio. Es. .ALIAS counter:U32, R8 — poi puoi scrivere MOV.S counter, 42.

!LI Rd, Imm    ; Carica immediato (numero o label)
!LI R1, 42     ; R1 = 42 (short form: MOV.S)
!LI R1, label  ; R1 = indirizzo di label (short form: MOV.S)
!LI R1, 70000  ; R1 = 70000 (long form: MOV.HIGH + OR.U)
!LU Rd, Imm    ; Carica unsigned 32-bit (numero o label)
!LU R1, 65535  ; R1 = 65535 (short form: MOV.U)
!LU R1, 70000  ; R1 = 70000 (long form: MOV.HIGH + OR.U)

6.7 Classi, interfacce, eventi e ABI

.CLASS Nome definisce una struttura con campi (.FIELD Nome:Tipo) e metodi (.METHOD Nome(param:TIPO)). Ogni classe genera un Class Descriptor (header con taglia + VTable con indirizzi dei metodi) per le chiamate virtuali (CALLM).

.INTERFACE Nome dichiara solo le firme dei metodi — un contratto che una classe può implementare con .CLASS Nome IMPLEMENTS Interfaccia. L'assembler verifica che tutti i metodi siano presenti.

.VECTOR Evento(ABI), Label collega un evento di sistema (es. EVT_RESET, EVT_TICK_1MS) a un handler nel tuo codice. L'ABI tra parentesi serve a validare i tipi dei parametri.

.ABI (nome:TIPO, ...) ... .END_ABI crea uno scope dove i registri vengono rinominati con nomi logici. Es. .ABI EVT_TICK_1MS(tick:FLG) ... MOV R8, tick .END_ABI.

.CLASS Contatore
    .FIELD value:U16
    .FIELD limit:U16

    .METHOD Init(limite:U16)
        MOV.S R1, 0
        ST16 R1, 4(R13)
        ST16 R2, 6(R13)
        RET
    .METHOD Incrementa
        LD16 R1, 4(R13)
        ADD.S R1, R1, 1
        ST16 R1, 4(R13)
        RET
.END_CLASS
.VECTOR EVT_RESET(flags:FLG), main
.VECTOR EVT_TICK_1MS(tick:FLG), on_tick

main:
    MOV.S R1, 0
    HALT
on_tick:
    ADD.S R1, R1, 1
    RET
.CONST MAX_SIZE, 256
.CONST TIMEOUT_MS, 5000

.IF defined(MAX_SIZE)
    MOV.S R1, MAX_SIZE
.END_IF

.ABI EVT_TICK_1MS(tick:FLG)
    MOV R8, tick          ; R8 = R1 (salva flag tick)
.END_ABI

6.8 Avanzate

.VM nome ... .END_VM delimita il codice di una VM in un sorgente che ne contiene piu di una. Il CLI (clasto) elabora ogni sezione separatamente e produce un file .magma (container multi-VM). Serve solo per firmware che esegue piu VM isolate.

.KEEP Rx ... .END_KEEP avvolge OGNI CALL/CALLM del corpo con PUSH Rx prima e POP Rx dopo (in ordine inverso, LIFO): preserva il valore corrente dei registri attraverso la singola chiamata (protezione per-call). Sostituisce il vecchio KEEP di .SCOPE (rimosso).

.WHILE Rd, Rs, COND ... .END_WHILE crea un ciclo a compile-time: confronta Rd con Rs, se la condizione COND (EQ/NE/GT/GE/LT/LE) e' falsa salta alla fine. Se la condizione resta sempre vera, il ciclo non termina.

.SHARED n imposta la memoria condivisa in KB (n >= 8). Se usato piu volte, prevale il valore massimo. .VM nome [n] imposta la memoria privata per quella VM.

.VM alpha
.FILE "alpha.clasto"
.VECTOR EVT_RESET(flags:FLG), main
main:
    MOV.S R1, 42
    HALT
.END_VM

.VM beta
.FILE "beta.clasto"
.VECTOR EVT_RESET(flags:FLG), main
main:
    MOV.S R1, 99
    HALT
.END_VM
