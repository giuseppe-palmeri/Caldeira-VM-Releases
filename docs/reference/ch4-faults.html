warning 4. Codici di fault

I fault sono errori software recuperabili tramite GUARD / UNGUARD. Quando si verifica un fault all'interno di un blocco protetto, la VM ripristina lo stato al checkpoint e scrive il codice in R14.

CodiceCostanteDescrizione
0x00USER_GENERICErrore generico utente
0x80NULL_POINTERAccesso a puntatore NULL (R1 = 0)
0x81INVALID_OBJPuntatore non punta a un oggetto valido
0x82OOM_SCRATCHOut Of Memory (Arena Scratch)
0x83OOM_FRAMEOut Of Memory (Arena Frame)
0x84STACK_OVERFLOWStack Pointer superato limite
0x85STACK_UNDERFLOWStack Pointer superato limite
0x86MARK_OVERFLOWMARK esauriti
0x87DIV_ZERODivisione per zero
0x88INVALID_OPCODEIstruzione non valida
0x89INVALID_PCPC non valido
0x8AEVENT_OVERFLOWEvent Queue piena
0x90BAD_CLASS_IDClassID non valido nella VTable
0x91NO_METHODMetodo non trovato nella VTable
0x92FIELD_BOUNDSAccesso fuori dai limiti dell'oggetto
0x94ILLEGAL_YIELDYIELD non consentito in questo contesto
0x95INVALID_CHARCarattere non valido in GETC/PUTC
0x96MARK_UNDERFLOWFREE/FREE.FR senza MARK/MARK.FR attivo
0x97UNGUARD_WITHOUT_GUARDUNGUARD senza GUARD attiva
0x98METHOD_BOUNDSIndice metodo fuori dai limiti nella VTable
0x99INVALID_EVENTEvent slot fuori range
0x9AINVALID_SYSCALLSyscall ID non valido
0x8BINVALID_READLettura da indirizzo non valido
0x8CINVALID_WRITEScrittura su indirizzo non valido (read-only o fuori memoria)
0x9BSTATIC_NOT_LOADEDLDA su .STATIC dichiarata ma non caricata (overflow del modello)
0xDEADDEADErrore fatale generico (ponte HW→VM)
